## 🎨 Design Tips

### Color Scheme
- Use high-contrast colors for text overlays
- Prefer white text with dark shadow/stroke
- Match overlay colors to app theme (cyan, pink, purple)
- Keep backgrounds slightly darkened for text readability

### Text Overlays
- **Font:** Bold, sans-serif (like Roboto Black, Montserrat ExtraBold)
- **Size:** Large enough to read on small phone screens
- **Placement:** Top or bottom third of image (not covering important UI)
- **Style:** All caps for main text, sentence case for subtitle

### Visual Elements
- Add subtle glow effects around important UI elements
- Use arrows or circles to highlight key features
- Keep UI clean - avoid clutter
- Show the app in actual use, not just static screens

## ✅ Quality Checklist

Before submitting screenshots:
- [ ] All text is readable at thumbnail size
- [ ] UI is shown in actual use (not just blank screens)
- [ ] Variety of screens shown (not all main screen)
- [ ] Colors are vibrant and eye-catching
- [ ] No pixelation or blur
- [ ] App branding is consistent
- [ ] Text overlays don't cover critical UI elements
- [ ] Screenshots tell a story/progression
- [ ] All features mentioned in description are shown
- [ ] Images optimized (compressed but high quality)

---

## 🚀 Pro Tips

1. **Order matters** - Put your best screenshot first
2. **Show, don't tell** - Visual demonstration beats text
3. **Consistency** - Use same theme/colors across screenshots
4. **Real usage** - Show actual boost levels (100%, 160%), not 0%
5. **Localize** - Create separate screenshots for different languages if possible
6. **Update regularly** - Refresh screenshots when you add major features
7. **A/B test** - Try different screenshot sets and monitor conversion rates
